## Install
1. **Download the code**
  ```
  git clone -b gh-pages https://github.com/mouafikmohammed/Business-Management-PHP-SQL-Javascript-HTML-CSS-.git
  ```
2. **import the database**<br>
  `import The file in [database SQL] folder in your host`

3. **Go to connection file and do:**<br>
   ```php
    $dbhost = "write here your host";
    $dbuser = "write here your user";
    $dbpass = "write here your db password";
    $dbname = "write here your db name";
    if(!$con = mysqli_connect($dbhost,$dbuser,$dbpass,$dbname))
    {
      die("failed to connect!");
    }
   ```
4. Good luck<br>
   ```php
    echo 'Good luck';
   ```
